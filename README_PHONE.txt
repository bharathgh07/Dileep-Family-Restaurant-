DILEEP BILLING - PHONE TEST

This is the installable PWA version.

IMPORTANT:
A PWA must be opened from an HTTPS website to install as an app. Opening index.html directly from a file manager will not show the Install App option.

Easiest test:
1. Put this folder on any HTTPS static host (for example GitHub Pages).
2. Open the site on your phone in Chrome.
3. Use the browser menu and choose "Install app" / "Add to Home screen".
4. Launch Dileep Billing from the new home-screen icon.

This version keeps the app's existing browser-local data behavior. It is for phone/UI testing, not yet shared between devices.
